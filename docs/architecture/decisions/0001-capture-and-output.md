# 0001. Отдельные циклы захвата и отправки кадров

Журнал Skydimo показал задержки перед автоматическим обновлением контроллера. Для «Контура» захват экрана и последовательную отправку разделили. Цикл отправки берёт последний пригодный кадр. В однотонном режиме отправляет тот же цвет с постоянным интервалом.

Открытие порта выполняется после команды пользователя. Формат контроллера проверяется перед отправкой RGB. Повтор подключения нужен при временной потере связи. Ошибки записи и интервалы от 150 мс фиксируются в локальном журнале, чтобы отличать задержку программы от физического мигания ленты.

WinForms и GDI выбраны из-за доступного на компьютере пользователя .NET Desktop Runtime 8 и возможности собрать приложение без дополнительных библиотек. Сложные сценарии HDR, эксклюзивного полноэкранного режима и защищённых окон требуют отдельной проверки или другого API захвата.
