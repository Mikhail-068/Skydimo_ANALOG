# Архитектура «Контура»

Локальное приложение WinForms на .NET 8 для Windows 10/11 x64. Снимок рабочего дерева от 21 ноября 2026 года, версия 0.9.2. Переносимый EXE и установщик включают среду .NET.

| Компонент | Ответственность |
|---|---|
| [Окно](../../MainWindow.cs) | Рычаг выбирает выключение, нейтраль N или рабочий режим. Нейтраль гасит подсветку и сохраняет последний рабочий режим. В нижнем ряду доступны цветомузыка по частотам звука Windows, цветовая волна и бегущие огни. Рабочий цикл формирует для них кадры SK0127 с учётом общей яркости. В авторежиме цикл подключает единственный CH340. Если устройств несколько, окно предлагает выбрать COM-порт. Ручной выбор сохраняется, а состояние показывает фактический порт. [Поле выбора USB](../../ControllerPicker.cs) открывает меню WinForms с собственным оформлением. [Панель настроек](../../SettingsSurface.cs) рисует фактуру для поля и переключателя автозагрузки без отрисовки соседних элементов. При выключении цикл освобождает контроллер. Верхнее положение левой ветки открывает полноразмерную палитру поверх настроек USB и автозагрузки. Закрытие палитры возвращает доступ к этим настройкам. Выбранный оттенок сразу передаётся рабочему циклу. Палитра остаётся видимой до смены положения рычага. Диалог «Другой цвет…» редактирует активную кнопку, её оттенок сохраняется в настройках. Регулятор яркости расположен под предпросмотром. [Схема дисплеев](../../MonitorSelector.cs) открывается слева от главного окна в любом режиме, отражает подключённые мониторы, выделяет выбранный источник захвата и обновляется при изменении конфигурации Windows. Если выбранный монитор исчезает, сохраняет его имя и ждёт возвращения или нового выбора. Окно отображает последнее состояние рабочего цикла. При закрытии крестиком окно скрывается в трей, рабочий цикл продолжает работу. Команда «Выход» освобождает контроллер и завершает приложение. В [предпросмотре](../../LedPreview.cs) вид сзади показывает маршрут 65 светодиодов. Маршрут можно нарисовать на задней стороне монитора. Настройки хранят 65 нормализованных точек от начала к концу. Захват экрана зеркально переводит координаты заднего вида в координаты экрана и берёт цвета в порядке ленты. Без своего маршрута используется штатная раскладка и настройка направления. [AmbientWall.cs](../../AmbientWall.cs) строит рассеянный ореол по цветам того же кадра. Цвета, отрисовка и управление элементами окна собраны в [WindowStyle.cs](../../WindowStyle.cs). |
| [Захват](../../DesktopCapture.cs) | Уменьшает кадр выбранного дисплея через GDI, усредняет цвет по 65 ячейкам. Изображение существует в памяти. Кадр помечается монитором, маршрутом ленты и временем получения. |
| [Захват звука](../../AudioLoopback.cs) | В режиме «Музыка» отдельный поток WASAPI считывает звук с аудиовыхода Windows по умолчанию и переключается при смене устройства. [Анализатор](../../AudioSpectrum.cs) выделяет бас, средние и высокие частоты. Короткая огибающая сравнивается с недавним средним уровнем каждой полосы, чтобы усилить звуковые акценты. Звуковые отсчёты хранятся только в памяти. |
| [Рабочие циклы](../../LightingEngine.cs) | Захват экрана и отправка кадров работают 20 раз в секунду. В музыкальном режиме цикл отправки преобразует три полосы частот в насыщенные смеси красного, зелёного и синего. Регулятор задаёт предельную яркость. Для предпросмотра и ленты использует один кадр. При сбое захвата, истекшем сроке кадра или смене источника плавно гасит последние цвета, пока не придёт подходящий кадр. |
| [Протокол и хранилище](../../Lighting.cs) | Раскладка 17 / 31 / 17, преобразование RGB и сборка 201-байтового сообщения. Локальные настройки в JSON с необязательным PreferredPort, журнал с ротацией. Старое поле Port использовалось как настройка по умолчанию, прежние файлы открываются в авторежиме. |
| [Автозагрузка](../../WindowsStartup.cs) | По переключателю записывает или удаляет команду запуска текущего EXE в Run текущего пользователя Windows. Положение [переключателя](../../StartupSwitch.cs) отражает состояние записи в реестре. Установщик при удалении убирает запись только для установленного EXE. |
| [COM-порт](../../SerialLink.cs) | Windows Win32 API, 115200 8N1, эксклюзивный доступ, отбор активных портов CH340 и идентификация SK0127. Запись кадров начинается после ответа контроллера. |

### Границы и проверка

- Для вывода нужен доступный USB-порт с устройством SK0127. В режиме предпросмотра приложение не занимает порт.
- Установщик NSIS размещает EXE и лицензии компонентов в `%LOCALAPPDATA%\Programs\Kontur`. При удалении настройки и журнал в `%LOCALAPPDATA%\KonturSK0127` сохраняются.
- Рабочие циклы обмениваются последними данными в памяти без очереди устаревающих кадров. Обновление цвета не складывается в очередь при временной задержке.
- Кадр подтверждён по локальному журналу установленной Skydimo и по формату совместимого драйвера. Журнал программы сохраняет ошибки и паузы, без дампа пикселей.
- Порядок светодиодов соответствует заводской раскладке SK0127. Физическая ориентация конкретной ленты проверяется по изображению на мониторе.

Описание [захвата выходного микса WASAPI](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording).

Источники для протокола и последовательного ввода-вывода: [описание протокола GlowSync](https://github.com/skybots-tg/glowsync#skydimo-protocol), [реализация драйвера HyperHDR](https://github.com/awawa-dev/HyperHDR/blob/master/sources/led-drivers/serial/DriverSerialSkydimo.cpp) и [настройка последовательного порта Windows](https://learn.microsoft.com/en-us/windows/win32/devio/configuring-a-communications-resource).
